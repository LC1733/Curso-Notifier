MOD 01

¿Qué es el Comisionamiento?

Definición, alcance y quién lo ejecuta

El comisionamiento es el proceso formal de verificar que un sistema de alarma de incendio recién instalado funciona correctamente, tal como fue diseñado y programado, antes de ser entregado al cliente y declarado operativo.

No es simplemente "encender el sistema y ver que no haya errores". Es una verificación sistemática, dispositivo por dispositivo, que incluye pruebas de alarma, pruebas de salidas de control, verificación de integración con otros sistemas y documentación completa.

NFPA 72 Cap. 14 exige que todo sistema sea comisionado por un técnico calificado antes de ser puesto en servicio. El acta de comisionamiento es un documento legal — puede ser requerido por la autoridad competente, compañías de seguros o el cliente en caso de incidente.

MOD 02

Pre-Comisionamiento

Lista de verificación antes de iniciar las pruebas — evita el 80% de los problemas

El pre-comisionamiento es la etapa más subestimada. Resolver problemas aquí toma minutos; resolverlos durante el walk test toma horas.

// Verificación física
Todos los dispositivos instalados — Comparar lista de dispositivos programados en VFT contra dispositivos físicamente instalados en campo. Cero diferencias.
Direcciones físicas verificadas — Confirmar que la dirección configurada en cada dispositivo (DIP switches o programador) coincide con la dirección en la base de datos VFT.
Continuidad de cableado — Medir resistencia del lazo SLC completo. Para NFS2-640: máximo 40 Ω. Verificar que no hay cortocircuitos ni circuitos abiertos antes de energizar.
Resistencias EOL en posición correcta — EOL al final de cada circuito NAC Class B. Verificar valor (4.7 kΩ) con multímetro antes de conectar.
Alimentación eléctrica — Verificar tensión AC en el panel: 120 VAC ± 10%. Circuito dedicado, protección correcta.
// Verificación del panel
Panel arranca en SYSTEM NORMAL — Al energizar, el panel no debe mostrar ningún TROUBLE ni ALARM pendiente. LED verde de POWER encendido fijo.
Baterías conectadas y cargando — Panel reporta baterías como NORMAL. Verificar tensión en bornes de batería: 26.5–27.6 VDC con cargador activo.
Base de datos descargada y verificada — Usar VFT Upload + Compare para confirmar que la base de datos del panel coincide con la versión aprobada del proyecto.
Fecha y hora del panel correctas — El panel registra eventos con timestamp. Sincronizar fecha/hora antes de iniciar pruebas. Error común: el panel queda con fecha de fábrica.
SLC polling sin errores — El panel debe reconocer todos los dispositivos del lazo sin reportar ningún dispositivo como MISSING o en TROUBLE.
Si el panel reporta dispositivos MISSING o TROUBLE antes de iniciar el walk test, detener el proceso. Resolver primero las fallas de comunicación del SLC — de lo contrario el walk test no tiene validez.
MOD 03

Walk Test

Verificación dispositivo por dispositivo — el núcleo del comisionamiento

El Walk Test es la prueba donde se activa cada dispositivo del sistema manualmente y se verifica que el panel lo recibe y registra correctamente. El nombre viene de "caminar" por el edificio activando detector por detector.

Se ejecuta con el panel en modo Walk Test (activado desde VeriFire Tools o directamente en el panel), que suprime la activación del NAC para no molestar a los ocupantes mientras se prueban los detectores.

01

Activar modo Walk Test en el panel

En VFT: Walk Test → Start Walk Test → Select All Devices. En el panel físico: menú de nivel 2 → Walk Test. El panel muestra "WALK TEST ACTIVE" y suprime los NAC.

02

Activar cada detector con aerosol de prueba

Usar aerosol de humo sintético (HFE-based) específico para detectores fotoeléctricos. Para detectores de calor usar pistola de calor. Nunca usar llama abierta ni humo real para pruebas.

03

Verificar respuesta en el panel y en VFT

El asistente en el panel confirma que el dispositivo correcto aparece en alarma con su dirección y etiqueta exactas. En VFT Status Monitor se puede ver la activación en tiempo real. Marcar como verificado en la lista.

04

Registrar resultado

Para cada dispositivo anotar: dirección, etiqueta, resultado (OK / FAIL), observaciones. Los dispositivos FAIL deben resolverse antes de finalizar el comisionamiento.

05

Finalizar Walk Test

Una vez probados todos los dispositivos: Walk Test → End Walk Test. El panel vuelve a modo normal. Verificar que el registro de walk test en el historial del panel queda guardado.

MOD 04

Verificación de Salidas de Control

NAC, FRM-1, FCM-1 — confirmar que el C&E funciona en campo

Una vez verificados todos los dispositivos de entrada (detectores, manuales), se deben verificar las salidas de control. Esta es la prueba más crítica desde el punto de vista de seguridad — es donde se confirma que el sistema realmente activa los equipos correctos en una emergencia.

Las pruebas de salidas de control deben coordinarse con los operadores del edificio. Activar el FCM-1 del HVAC puede apagar sistemas críticos. Activar el relé de puertas puede trabarlas en posición abierta. Coordinar siempre con el cliente antes de ejecutar estas pruebas.

NAC-1 (sirenas) Activar alarma desde detector o manual de prueba Confirmar audición de sirenas en todas las áreas del circuito ≥15 dB sobre ruido ambiental o ≥75 dB a 3m en cada punto
NAC strobes Activar alarma Confirmar destello visual en zonas definidas por NFPA 72 §18 Visible desde cualquier punto de la zona cubierta
FRM-1 (relé) Activar zona correspondiente según C&E Medir continuidad en contactos del relé con multímetro Contacto NA cierra / NC abre según programación
FCM-1 (ventilador) Activar zona correspondiente Confirmar arranque/detención del ventilador + señal de feedback OK en panel Panel confirma feedback dentro de tiempo programado
Shunt Trip MCCB Activar zona con panel en modo prueba aislado Confirmar disparo del interruptor eléctrico MCCB dispara en ≤2 segundos desde activación del relé
Transmisión central Activar alarma real o de prueba Confirmar recepción en central de monitoreo remoto Central confirma recepción en ≤90 segundos (NFPA 72)

MOD 05

Integración con Sistemas Auxiliares

HVAC, control de acceso, PA, ascensores y supresión

El sistema NOTIFIER no opera en aislamiento — en proyectos industriales y edificios complejos se integra con múltiples sistemas. Cada integración debe ser verificada durante el comisionamiento con los responsables de cada sistema presente.

SistemaMódulo NOTIFIERAcción en alarmaVerificación requerida
HVAC / Ventilación FCM-1 Apagar/encender según zona. Activar modos de presurización o extracción de humos Confirmar operación del equipo + señal de feedback en panel
Control de acceso FRM-1 (relé libre) Liberar puertas de emergencia magnéticas o electromecánicas Confirmar apertura física de puertas con personal de seguridad
Sistema PA (anuncio) FRM-1 o contacto de control Activar mensaje pregrabado de evacuación o silenciar música/anuncios Confirmar reproducción del mensaje correcto en todas las zonas PA
Ascensores FRM-1 (recall) Enviar todos los ascensores al piso de recepción y mantenerlos abiertos Confirmar recall con empresa de ascensores presente. Crítico para bomberos
Supresión (sprinkler/gas) MMX-1 (supervisión) + FRM-1 (activación) Recibir señal de flujo de agua / activar supresión con gas en área protegida Solo prueba en seco (sin agente) durante comisionamiento. Verificar con empresa de supresión
Generador de emergencia MMX-1 (monitoreo) Monitorear estado del generador; reportar falla al panel como supervisory Simular falla de generador y verificar señal supervisory en panel
BMS / BACnet Protocolo BACnet integrado en panel Reportar estado del sistema de incendio al BMS del edificio Verificar con el integrador del BMS que los puntos de datos son correctos
Coordinar siempre con anticipación: Las pruebas de integración con HVAC, ascensores y supresión deben avisarse al cliente con al menos 24 horas de anticipación. Algunos sistemas requieren que su fabricante o instalador esté presente durante la prueba.
MOD 06

Documentación y Entrega

Acta de comisionamiento, as-builts y entrega formal al cliente

El comisionamiento no termina cuando el sistema funciona — termina cuando todo está documentado y firmado. La documentación es el respaldo legal del instalador y la guía operacional del cliente.

// Documentos obligatorios de entrega
Acta de comisionamiento firmada — Documento que certifica que el sistema fue instalado, programado y probado según NFPA 72. Debe ser firmado por el técnico responsable y el representante del cliente.
Planos as-built — Planos actualizados que reflejan la instalación real, incluyendo cualquier cambio respecto al diseño original. Formato PDF y DWG si el cliente lo requiere.
Base de datos VFT respaldada — Copia del archivo .vfd entregada al cliente en USB y/o correo. Esta es la "llave" del sistema — sin ella no se puede reprogramar el panel.
Registro de walk test — Lista firmada con resultado de prueba de cada dispositivo: dirección, etiqueta, resultado (OK/FAIL), fecha y técnico responsable.
Manual de operación para el cliente — Guía simplificada de operación cotidiana: cómo responder a una alarma, cómo silenciar, cómo resetear, qué significa cada LED, a quién llamar en caso de falla.
Programa de mantenimiento — Calendario de mantenimiento preventivo según NFPA 72 Cap. 14: pruebas semestrales de detectores, prueba anual del sistema completo, reemplazo de baterías.
Contraseñas del panel documentadas — Nivel 1 (operador) y Nivel 2 (instalador) entregadas en sobre cerrado o sistema seguro de gestión de credenciales.
Acta de Comisionamiento — Generador NFPA 72 CAP. 14
El sistema está listo para entrega cuando: panel en SYSTEM NORMAL, 100% dispositivos verificados en walk test, todas las salidas C&E verificadas en campo, todos los documentos firmados y entregados al cliente.
